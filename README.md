# Road-Safety-Analytics-India-2022-2023
## 📊 Overview
Power BI dashboard analyzing 1,000 road accident 
records across Indian states (2022-2023)

## 🔑 Key Insights
- 32.5% of accidents result in fatalities
- Fog is most dangerous weather condition
- TR & DL are highest accident states
- March sees peak accidents annually

## 🛠️ Tools Used
- Power BI Desktop
- DAX
- Power Query
